## ما هو Time Log؟

Time Log تطبيق ويب بسيط وأنيق يساعدك على **تتبّع كيف تقضي وقتك** طوال اليوم — بدون تعقيد وبدون ضغط.

الفكرة الأساسية: كل ساعة في يومك لها خانة، تكتب فيها ما فعلته، وتختار تصنيفاً، وفي نهاية اليوم أو الأسبوع تحصل على صورة واضحة عن حياتك الفعلية.

---

## ✨ ماذا يقدم لك؟

### 📋 تسجيل الوقت بالساعة
- سجّل ما تفعله في كل ساعة بكلمات بسيطة
- صنّف نشاطك (عمل، راحة، رياضة، تعلّم...)
- رتّب أولوياتك اليومية بجانب سجلك

### 🎯 مؤقت بومودورو مدمج
- ابدأ جلسة تركيز بضغطة واحدة
- تنتهي الجلسة وتُسجَّل تلقائياً في الساعة الصحيحة
- أصوات محيطة وتنبيهات اختيارية

### 🔍 بحث شامل في تاريخك
- ابحث في كل ما سجّلته عبر الأيام والأسابيع
- ابحث بالتاق أو بالكلمة
- **بحث متسامح:** يتجاوز الأخطاء الإملائية وتنويعات الحروف العربية (أ/ا، ى/ي، ة/ه)
- رتّب النتائج كيفما تريد — أو اختر «الأنسب أولاً»

### 📊 تقارير وإحصاءات
- شاهد توزيع وقتك على مدار الأسبوع
- مخططات بيانية واضحة لأنشطتك
- ملخص يومي وأسبوعي

### 🌙 حصاد المساء (اختياري)
- مراجعة خفيفة لليوم المنتهي من الساعة 5 صباحاً
- إجمالي ساعاتك، توازن جوانب حياتك، وأكثر ما كررته
- يمكن تفعيله أو تعطيله من الإعدادات

### 🎨 مظاهر وثيمات
- فاتح / داكن / تلقائي (يتابع إعدادات جهازك)
- 6 ثيمات ألوان: كلاسيكي، محيط، غابة، غروب، وردي، ورقي — من الإعدادات

### ☁️ مزامنة سحابية
- سجّل الدخول وبياناتك تُحفظ في السحابة
- وصول من أي جهاز
- نسخ احتياطية كاملة بضغطة واحدة

## 🎓 كيف تبدأ؟

1. **افتح التطبيق** — ستجد جدول اليوم الحالي جاهزاً
2. **اكتب في أي ساعة** — فقط اضغط على الخانة واكتب
3. **اختر التاق** — صنّف النشاط (E الكسب، V الرؤية، R التعافي، S الخدمة، SC الرعاية الذاتية)
4. **استخدم البومودورو** — اضغط 🎯 لبدء جلسة تركيز مؤقتة
5. **تصفّح أسابيعك** — استخدم الأسهم للتنقل بين الأسابيع السابقة

## 🛠️ للمطوّرين

**التقنيات:** React 19 · TypeScript · Vite · Tailwind CSS 4 · Firebase (Auth + Firestore) · PWA · Vitest

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck  # tsc --noEmit
npm run lint
npm test
npm run build
```

**تشغيل نسختك الخاصة:** أنشئ مشروع Firebase، فعّل Authentication (Google + Email) وFirestore، ضع إعدادات الويب في `src/services/firebase.ts`، وانشر القواعد:

```bash
npx firebase-tools deploy --only firestore:rules
```

### 🛡️ الأمان (Security)

مفتاح Firebase في الكود **ليس سراً**؛ هو مجرد معرّف للمشروع، والحماية الحقيقية في `firestore.rules` (كل مستخدم يرى بياناته فقط). وللحماية الإضافية:

1. **تقييد مفتاح API:** Google Cloud Console → APIs & Services → Credentials → مفتاح المتصفح → *Website restrictions*: أضف `time-log-rouge.vercel.app/*` و`localhost:3000/*` (ونطاقك الخاص لاحقاً).
2. **App Check:** Firebase Console → App Check → سجّل تطبيق الويب بـ **reCAPTCHA v3**، وانسخ الـ *site key* إلى Vercel كمتغير `VITE_RECAPTCHA_SITE_KEY`، ثم أعد النشر. راقب الطلبات أسبوعاً في تبويب App Check، وبعدها اضغط **Enforce** لـ Firestore وAuthentication.
